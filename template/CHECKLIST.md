# Check by hand (a real session)

Run `claude --plugin-dir ./` with binnacle installed from its marketplace.

- [ ] `✋ hello` shows at the right of the footer, before `☰ binnacle`.
- [ ] Clicking it shows `hello, once`; clicking again counts up.
- [ ] `/binnacle` → Settings → Plugins lists `binnacle-hello` and `[ ] Shout the greeting`; turn it on and click the button: the greeting is in capitals.
- [ ] Turn `binnacle-hello` off in Settings: the button goes; turn it on: it comes back.
- [ ] `/clear`: the button is still there and still works.
